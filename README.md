### 01 战意兵团养成系统分析

围绕一个问题展开：为什么一支新兵团获取后，往往要很久才正式上阵？先介绍攻城流程与兵团用途，再以马其顿方阵与马耳他远征骑士为案例，拆解训练、军魂、潜能、经验与重置，最后从资源产出、等级门槛和资源竞争三个角度给出判断。

### 02 《王国保卫战》第一关系统拆解

从规则层面拆解战役第一关，覆盖从开波到结算的 11 个子系统：波次调度、路径与漏怪、防御塔、兵营阻挡、伤害结算、经济闭环、英雄成长、主动技能、前后端事件与随机性。所有规则和数值来自将该关迁移到 Unreal Engine 时对原作规则的逐项阅读与对照验证。

配套数值表含伤害计算器、逐波经济模拟和建造点覆盖计算，改一个输入全表联动。打开后先看「说明」页。
